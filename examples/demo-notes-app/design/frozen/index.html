Notes that sit next to your code.

DevNotes keeps snippets, runbooks and half-written thoughts as plain Markdown in a folder you own. Full-text search runs offline. Sync is a git remote you already have.

  • Plain Markdown files

Three things it does, none of them clever

Everything works from a folder, a terminal and the editor you already use. Nothing is stored in a place you cannot open with cat.

One keystroke, one index, no requests

DevNotes builds an index over your folder the first time you open it, then updates it when a file changes on disk.

  • Ranked by title, path and recency. Not by engagement.
  • Opens the file at the line that matched.
  • Works on a plane, in a tunnel, behind a proxy.

A snippet is a file, not a row

Snippets are Markdown with front matter. Copy one into a project, commit it, `grep` it, delete it. Nothing is locked inside DevNotes.

  • Front matter carries tags, language and the date you wrote it.
  • Fenced code blocks keep syntax highlighting in any editor.
  • An index line links a snippet back to the file that needed it.
snippets/postgres.mdmarkdown
---
title: Find slow queries
tags: [postgres, perf]
---
SELECT query, calls, mean_exec_time
FROM pg_stat_statements
ORDER BY mean_exec_time DESC
LIMIT 20;

Sync is a remote you already own

Point DevNotes at a git remote and it commits on a schedule. Conflicts are plain files, resolved in your editor, not in a proprietary merge screen.

  • One commit per sync, message written from the changed files.
  • Read-only mode when the remote is unreachable.
  • History lives in git, so it outlives this app.

What leaves the app is the same file you wrote

Copy a snippet into a project and it still reads the same. No export step, no proprietary format, no migration page when you leave.

~/devnotes/snippets/react.md 
---
title: Debounce a value in React
tags: [react, hooks]
written: 2026-10-14
---

import { useEffect, useState } from "react";

export function useDebounced<T>(value: T, ms = 250): T {
  const [settled, setSettled] = useState(value);

  useEffect(() => {
    const id = setTimeout(() => setSettled(value), ms);
    return () => clearTimeout(id);
  }, [value, ms]);

  return settled;
}
